# Travel Destination Website

A multi-page travel destination website built with HTML and CSS as part of my web development assignment at Aptech.

## Live Demo

https://fardeenkhannaveed.github.io/TravelDestination/

## Pages

- **Home** (`index.html`): landing page with navigation and featured content
- **Destinations** (`Destinations.html`): travel destinations with images
- **Booking Form** (`bookingForm.html`): form to book a trip
- **FAQ** (`faq.html`): frequently asked questions
- **Feedbacks** (`feedbacks.html`): customer feedback section

## Technologies Used

- HTML5
- CSS3

## Project Structure

```
travel-destination/
├── Assets/            # images and media
├── index.html
├── Destinations.html
├── bookingForm.html
├── faq.html
├── feedbacks.html
└── style.css
```

## How to Run Locally

1. Clone the repository:
   ```
   git clone https://github.com/fardeenkhannaveed/travel-destination.git
   ```
2. Open the folder in VS Code.
3. Open `index.html` in your browser.
